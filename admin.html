ADMIN RECOVERY V66 — GITHUB MAIN

1. Sorgenti e importazione

Connessione GitHub con token personale temporaneo. Il token non viene salvato nel browser né nei file esportati. L'autorizzazione viene verificata da GitHub, non da una chiave nascosta nell'HTML.

2. Controllo integrità e anteprima

Nessun file importato.

3. Esportazione e recupero

Esporta i file originali senza ricostruire le pagine. Per un backup unico cifrato, inserisci una chiave segreta scelta da te. Usa la stessa chiave nell'ADMIN interno e in quello esterno: non viene incorporata nei file HTML.

Importare un pacchetto sostituisce soltanto le copie in memoria dell'ADMIN, non i file GitHub.

4. Ripristino GitHub — azione esplicita

Pubblicazione disabilitata fino a verifica dell'accesso, caricamento di entrambe le pagine, controllo integrità e conferma. Viene ripristinato soltanto il file scelto. Prima scarica una copia del file attualmente presente su GitHub. Nessun ripristino automatico.

Registro operativo

Pronto. Nessuna modifica online.
